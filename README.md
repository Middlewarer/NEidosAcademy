## О проекте

**EidosAcademy** — личный проект образовательной веб-платформы. Его задача — объединить каталог курсов, учебные материалы и отслеживание прогресса в одном приложении.

В предыдущей версии реализованы структура учебного контента, REST API, регистрация и авторизация, личный кабинет и работа с прогрессом обучения. Этот репозиторий предназначен для новой реализации с пересмотром архитектуры и организации кода.

Переработка начинается с моделей данных и основных пользовательских сценариев. Функции будут переноситься постепенно, с проверкой поведения и документированием принятых решений.

## Текущий статус

**Проект находится на начальном этапе переработки.** Создан новый репозиторий; реализация новой версии только начинается.

Ссылка на `eidosacademy.ru` относится к пока предыдущей версии

## Цели переработки

- Уточнить модель учебного контента и связи между курсами, модулями, темами и материалами.
- Разделить ответственность между компонентами приложения и упростить внесение изменений.
- Определить единые правила валидации, обработки ошибок и проверки прав доступа в API.
- Покрыть тестами основные сценарии и пограничные случаи по мере их реализации.
- Подготовить понятные инструкции запуска и документацию по устройству проекта.

## Планируемые возможности

| Область         | Возможности                                                                     |
| --------------- | ------------------------------------------------------------------------------- |
| Учебный контент | Категории, курсы, модули, темы и материалы                                      |
| Каталог         | Просмотр опубликованных курсов, поиск и фильтрация                              |
| Пользователи    | Регистрация, вход, профиль и разграничение доступа                              |
| Обучение        | Запись на курс, сохранение прогресса и продолжение с последнего материала       |
| Управление      | Работа с учебным контентом через Django Admin                                   |
| API             | Интерфейс для клиентского приложения с документацией и проверкой входных данных |

## Технологическая основа

Основой новой версии планируются технологии, использованные в предыдущем проекте:

| Назначение      | Технологии                                                                             |
| --------------- | -------------------------------------------------------------------------------------- |
| Серверная часть | Python, Django                                                                         |
| API             | Django REST Framework                                                                  |
| Хранение данных | PostgreSQL, Django ORM                                                                 |
| Тестирование    | Тесты моделей и API; конкретная конфигурация будет зафиксирована при настройке проекта |
| Контроль версий | Git, GitHub                                                                            |

Подход к клиентской части, авторизации и развёртыванию будет уточняться по мере проектирования. Зависимости и их версии будут закреплены в репозитории после настройки окружения.
